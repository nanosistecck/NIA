# Instalação do pacote de especificações
Extraia o ZIP na raiz da NIA, preservando pastas ocultas. Não sobrescreva registros de progresso de uma instalação anterior; faça backup e mescle se houver conflito. As skills ficam em .agents/skills (formato SKILL.md); se o agente não as descobrir automaticamente, leia-as explicitamente ou use o mecanismo de skills já configurado. Não há instalador de dependências nem código de runtime neste pacote: o agente implementará após auditoria. Abra OpenCode ou Codex na raiz e envie o prompt de prompts/adaptive_learning/00_PROMPT_MASTER.md. Para retomar use 02_RESUME_IMPLEMENTATION.md. Não publique memória privada ou logs. Os nomes e metas são propostas a verificar no código real.
