# Agenda da NIA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Criar a Agenda independente da NIA, com janela no dock, comandos de chat/voz e card de próximo compromisso no Canvas principal.

**Architecture:** Módulo puro de dados (`core/agenda.py`) com JSON atômico por perfil; parser puro de comandos (`core/comandos_agenda.py`); janela PyQt6 (`core/interface_agenda.py`); integração pontual em `main.py`, `ui.py`, `core/interface_canvas.py` e `core/config_dashboard.py`. Nada altera planos ou lembretes existentes.

**Tech Stack:** Python 3.12, PyQt6, pytest, padrões existentes de `resumo_dia.py`, `CanvasStage.hoje_host`, `VerticalDock`.

**Spec:** `docs/superpowers/specs/2026-11-23-agenda-design.md`

## Global Constraints

- Dados em `~/.nia/agenda.json`, override por `NIA_AGENDA`, chave por `NIA_PERFIL`.
- Gravação atômica com `.tmp` + `replace`, como `core/resumo_dia.py`.
- Nenhuma rede, credencial, dependência nova ou mudança de formato de planos.
- Estados: `pendente`, `concluido`, `cancelado`. Tipos: `reuniao`, `chamada`, `tarefa`, `entrega`, `viagem`, `aniversario`, `outro`.
- Preparo padrão (min): reuniao/chamada 15; tarefa/entrega 30; viagem 60; aniversario 120; outro 30. Editável.
- Alvo de comando sem ID: título/data ditos → senão próximo → se ambíguo, perguntar.
- Card vai no Canvas principal (`CanvasStage`), nunca no overlay de planos.
- Nenhuma afirmação de validação visual sem captura da interface executada.

## Review Focus

1. Pedido sem data/hora → não criar; responder "Informe a data e a hora". Teste em Task 2.
2. Dois compromissos com o mesmo título → não alterar; perguntar qual. Teste em Task 2.
3. Card fechado e reaberto → preferência `cards.agenda` persistida. Teste em Task 5.
4. "bom dia" sem compromisso → saudação normal, sem inventar. Teste em Task 3.
5. Compromisso vencido → `proximo()` ignora; `listar()` continua mostrando. Teste em Task 1.
