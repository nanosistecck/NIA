# Integração SDK

Descobrir contratos reais; registrar capacidades de plugins em instalação/remoção/atualização. Adaptadores para ferramentas existentes, permissões e provedores. Não contornar executor central. Procedimentos não concedem privilégios. Lacunas de ferramentas podem gerar especificação para Factory, sujeita a aprovação e testes. Não alterar configurações globais nem instalar dependências sem verificar compatibilidade/licença.

## Gate
Registrar implementação real, caminhos, testes, evidências, limitações e próximo passo no diretório progress. Não marcar concluído sem verificação.
